How to read this page

Each version represents a coherent body of work, not just a count. The directory grows by denomination family and geographic coverage — not by bulk import. Every new record is verified pastor + working website + real address + theological scoring across 10 dimensions.

Status labels: Done = shipped + pushed; Current = in progress; Planned = scoped but not started. Target dates assume one focused 3–5 hour sprint per version, fired against a fresh weekly subscription budget.

What this is and isn't

This directory is one Marine veteran's discernment ledger, not an official seal of approval from any denominational body. The 10-dimension scoring, signatory cross-references, and drift documentation reflect a conservative-orthodox-confessional theological frame; readers from other frames should weigh accordingly.

The roadmap above is best-effort planning, not a contract. Dates assume continued availability of subscription budget + denomination directories staying online + agents continuing to verify cleanly. The directory is shipped openly so anyone can audit, dispute, or fork the data.
