H4549 · Hebrew · Old Testament
מָסַס
mâçaç
discourage, faint, be loosed, melt (away), refuse, [idiom] utterly.

Definition

mâçaç (מָסַס) is Hebrew Strong's H4549. Strong's defines it as to liquefy; figuratively, to waste (with disease), to faint (with fatigue, fear or grief). Strong's traces the form: a primitive root. The Authorised Version renders it discourage, faint, be loosed, melt (away), refuse, [idiom] utterly. The tagged KJV carries this code 20 times, across 11 books: Exodus, Deuteronomy, Joshua, Judges, 1 Samuel, 2 Samuel, Psalms, Isaiah, and others.

Usage & Theological Significance

Every verse below is one the tagged KJV marks with H4549, so each is a place the Hebrew word itself stands behind the English rather than a translator's paraphrase. The first is Exodus 16:21. The code is spread over 11 books, which is worth weighing before treating any single rendering as the whole sense of the word. Where the Authorised Version gives more than one English word for it, that difference is the translators' judgement about context, not a second Hebrew word underneath.
