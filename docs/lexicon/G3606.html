G3606 · Greek · New Testament
ὅθεν
hóthen
from thence, (from) whence, where(-by, -fore, -upon)

Definition

hóthen (ὅθεν) is Greek Strong's G3606. Strong's defines it as from which place or source or cause (adverb or conjunction). Strong's traces the form: from G3739 (ὅς) with the directive enclitic of source. The Authorised Version renders it from thence, (from) whence, where(-by, -fore, -upon). The tagged KJV carries this code 15 times, across 5 books: Matthew, Luke, Acts, Hebrews, 1 John.

Usage & Theological Significance

Every verse below is one the tagged KJV marks with G3606, so each is a place the Greek word itself stands behind the English rather than a translator's paraphrase. The first is Matthew 12:44. The code is spread over 5 books, which is worth weighing before treating any single rendering as the whole sense of the word. Where the Authorised Version gives more than one English word for it, that difference is the translators' judgement about context, not a second Greek word underneath.
