H3976 · Hebrew · Old Testament
מֹאזֵן
môʼzên
balances.

Definition

môʼzên (מֹאזֵן) is Hebrew Strong's H3976. Strong's defines it as (only in the dual) a pair of scales. Strong's traces the form: from H239 (אָזַן). The Authorised Version renders it balances. The tagged KJV carries this code 15 times, across 10 books: Leviticus, Job, Psalms, Proverbs, Isaiah, Jeremiah, Ezekiel, Hosea, and others.

Usage & Theological Significance

Every verse below is one the tagged KJV marks with H3976, so each is a place the Hebrew word itself stands behind the English rather than a translator's paraphrase. The first is Leviticus 19:36. The code is spread over 10 books, which is worth weighing before treating any single rendering as the whole sense of the word. Where the Authorised Version gives more than one English word for it, that difference is the translators' judgement about context, not a second Hebrew word underneath.

Key Bible Verses
