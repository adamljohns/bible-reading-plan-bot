H8111 · Hebrew · Old Testament
שֹׁמְרוֹן
Shômᵉrôwn
Samaria.

Definition

Shômᵉrôwn (שֹׁמְרוֹן) is Hebrew Strong's H8111. Strong's defines it as Shomeron, a place in Palestine. Strong's traces the form: from the active participle of H8104 (שָׁמַר); watch-station. The Authorised Version renders it Samaria. The tagged KJV carries this code 101 times, across 11 books: 1 Kings, 2 Kings, 2 Chronicles, Nehemiah, Isaiah, Jeremiah, Ezekiel, Hosea, and others.

Usage & Theological Significance

Every verse below is one the tagged KJV marks with H8111, so each is a place the Hebrew word itself stands behind the English rather than a translator's paraphrase. The first is 1 Kings 13:32. The code is spread over 11 books, which is worth weighing before treating any single rendering as the whole sense of the word. Where the Authorised Version gives more than one English word for it, that difference is the translators' judgement about context, not a second Hebrew word underneath.
