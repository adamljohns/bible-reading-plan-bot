H6973 · Hebrew · Old Testament
קוּץ
qûwts
abhor, be distressed, be grieved, loathe, vex, be weary.

Definition

qûwts (קוּץ) is Hebrew Strong's H6973. Strong's defines it as to be (causatively, make) disgusted or anxious. Strong's traces the form: a primitive root (identical with through the idea of severing oneself from (compare H6962 (קוּט))). The Authorised Version renders it abhor, be distressed, be grieved, loathe, vex, be weary. The tagged KJV carries this code 9 times, across 7 books: Genesis, Exodus, Leviticus, Numbers, 1 Kings, Proverbs, Isaiah.

Usage & Theological Significance

Every verse below is one the tagged KJV marks with H6973, so each is a place the Hebrew word itself stands behind the English rather than a translator's paraphrase. The first is Genesis 27:46. The code is spread over 7 books, which is worth weighing before treating any single rendering as the whole sense of the word. Where the Authorised Version gives more than one English word for it, that difference is the translators' judgement about context, not a second Hebrew word underneath.
