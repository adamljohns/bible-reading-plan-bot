H7493 · Hebrew · Old Testament
רָעַשׁ
râʻash
make afraid, (re-) move, quake, (make to) shake, (make to) tremble.

Definition

râʻash (רָעַשׁ) is Hebrew Strong's H7493. Strong's defines it as to undulate (as the earth, the sky, etc.; also a field of grain), particularly through fear; specifically, to spring (as a locust). Strong's traces the form: a primitive root. The Authorised Version renders it make afraid, (re-) move, quake, (make to) shake, (make to) tremble. The tagged KJV carries this code 30 times, across 11 books: Judges, 2 Samuel, Job, Psalms, Isaiah, Jeremiah, Ezekiel, Joel, and others.

Usage & Theological Significance

Every verse below is one the tagged KJV marks with H7493, so each is a place the Hebrew word itself stands behind the English rather than a translator's paraphrase. The first is Judges 5:4. The code is spread over 11 books, which is worth weighing before treating any single rendering as the whole sense of the word. Where the Authorised Version gives more than one English word for it, that difference is the translators' judgement about context, not a second Hebrew word underneath.
