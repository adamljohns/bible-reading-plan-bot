      How to read this

      • The Claude card above is the real meter. It comes live from Claude's own usage reading. This section is our measurement of what used it.
      • Points are estimates. One meter point is about 2.8 "weighted Mtok", give or take 50%. Trust the ranking and the shares. Treat the point numbers as rough.
      • Context size is what burns the meter, not how much an agent writes. A long-running chat re-reads its whole history on every turn.
      • Agent-to-agent messages are charged to the agent that receives them. A drill-down shows who sent them, and what each agent causes on others.
      • Scheduled jobs on Max include "relays": a job owned by another agent whose output Max then had to process.
      • Heartbeats run on the local model, so they barely show. Grok and GPT do not count against Claude; their call counts are listed for context only.
      Method and caveats

      • Source: the Claude Code session logs on the fleet host Mac. Each API call is counted once (deduplicated by message id).
      • Agent = the workspace the call ran in. Source = the message that opened that turn.
      • Weights: input 1, cache write 1.25, cache read 0.1, output 5; Sonnet ×0.6, Haiku ×0.2 (API price ratios).
      • Not measured: claude.ai web/mobile chats and Claude Desktop chats (not on disk). Grok reports no token counts, so it shows calls only.
      • Counts only. No message text, prompts or chat ids are published.
